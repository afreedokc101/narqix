## What "tracker" means on this page

A tracker here is the **one-line-per-item view of the work:** a shared spreadsheet or a board or list view inside the CRM. It is not the time-tracking tool you use for your hours. Your client's setup may name columns differently. Map them to these standards and agree any differences with your Campaign Lead in writing.

## Rules for every tracker

1. **One row per item:** one lead, one deal, one file or one order. Never two items on one row.
2. **One owner per row,** named in the Owner column.
3. **Every open row has a next action and a due date** with the time zone.
4. **Approved values only** in Status, Stage, Code, Heat and Flag columns. Use dropdowns where the tool allows. Never invent a value.
5. **Dates in one format** across the tracker; times always with the zone named.
6. **Update the same shift** you touch the item. The tracker must show the true status at all times.
7. **Never delete rows.** Close them with a status (Dead, Closed, Paid) and a reason.
8. **No sensitive data:** no Social Security numbers, full bank or card numbers, full dates of birth, ID copies, passwords or lockbox and gate codes.
9. **Bulk changes** to more than 50 rows need written approval and a backup export first.
10. **Sort by due date** when you open it. The oldest due date is the next thing you touch.

## Lead tracker

For seller, homeowner, merchant or customer leads before a deal or booking: Real Estate (calling, SMS, lead management), Solar, HVAC outbound, Strategic Funding.

| Column | What goes in it | Example |
| --- | --- | --- |
| Lead ID | CRM record ID | (LEAD ID) |
| Name | Owner, homeowner or business legal name | (SELLER NAME) |
| Property or business | Address, or legal name and DBA | (PROPERTY ADDRESS) |
| State and time zone | Two-letter state, zone | TX, CT |
| Source and date | List, form, inbound, referral; date received | Probate list, Oct 14 |
| Consent | Call, text, email: Yes or No, with date | Text Yes, Oct 19 |
| Owner | Person responsible for the next step | (YOUR NAME) |
| Stage | Your track's pipeline stage | Warm Follow-Up |
| Last code | Last disposition or outcome code | FU-WARM |
| Temperature or grade | Hot, Warm, Nurture, Dead (or track grade) | Warm |
| Attempts today and total | Count, for attempt caps | 1 today, 6 total |
| Last touch | Date, time and zone, channel | Oct 19, 6:20 PM CT, call |
| Next action | What happens next | Call after family talk |
| Next action due | Date, time and zone | Oct 26, 6:00 PM CT |
| DNC | Yes or No (Yes stops all contact on every campaign) | No |
| Notes link | Link to the CRM record | (LINK) |

**Track codes:** Real Estate uses the Narqix standard set (NA / VM, BUSY / DISC, WRONG, DNC, NI, CB, FU-WARM, HOT, APPT, LISTED / AGENT, SOLD, LIT-FLAG). Solar uses its own set (NEW, NA, VM, WN, DISC, LANG, CB, NI, DQ, NUR, SET, LT, CONF, RESCH, CXL, NS, SAT, SAT-INC, DNC). Funding uses its file statuses (for example Docs Pending, Submitted, Stips, Offer Out, Declined, Funded).

<div class="callout callout-coach">

**Coach's note:** Build your tracker so the last three columns are always Next action, Owner and Due. When a client or lead opens it, those three columns answer the only question they really have: what happens next, who does it, and when.

</div>

<div class="callout callout-never">

**Never do this:** Never add a new status, code or flag value because it is convenient for you. Never delete a row to hide a dead lead, file or order. Never paste codes, passwords or personal identity numbers into a tracker cell.

</div>

## Check yourself

1. Which three columns does every open row need?
2. A lead asks to stop all contact. Which tracker column changes, and what does it mean?
3. Name five TC status values.
4. An order was returned by the client. What status does it take, and which column explains why?

<details class="toggle toggle-answers"><summary>Answers</summary>

1. Next action, owner, and next action due (with time zone).
2. DNC becomes Yes and the last code is DNC. It stops all contact on every campaign.
3. Any five of: NEW, TITLE-OPEN, EMD-PENDING, SEARCH, CURATIVE, MARKETING, BUYER-LOCKED, CTC, SS-REVIEW, SIGNING, FUNDING, POST, CLOSED, HOLD, CANCEL-PENDING, DEAD.
4. Rejected. The Rejection reason column records the client's reason.

</details>
